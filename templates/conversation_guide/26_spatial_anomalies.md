# 26. Dimensional, Extra-Planar & Spatial Anomalies

## Grammatical Mapping & Analysis
When translating this category into a target language, conlangers and linguists should establish the following grammatical features:
1. **Locative Shifting Cases**: Spatial anomalies warp space. Design grammatical markers for position shifts, where locative endings change dynamically (e.g., "I am here-but-shifting-there").
2. **Spatial Preverbs**: Create verb prefixes indicating motion in distorted axes (e.g., "folding-through", "phasing-out").
3. **Passive Structural Verbs**: Formulate grammar for events where the physical layout itself changes (e.g., "the corridor elongated", "the gravity reversed").
4. **Extreme Conditional Syntax**: Develop conditional prefixes that address time-dilation or causality shifts (e.g., "If I return before I left...").
