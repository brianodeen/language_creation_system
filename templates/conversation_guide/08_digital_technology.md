# 8. Digital, Technology & Logic

## Grammatical Mapping & Analysis
When translating this category into a target language, conlangers and linguists should establish the following grammatical features:
1. **Instrumental Passive**: Define how to describe actions performed *by means of* a device or software tool (e.g., "compiled *via terminal*", "encrypted *with the algorithm*").
2. **Causative Verbal Extensions**: Create specific verb forms that mean "to make/cause a machine to do something" (e.g., *to run* $\rightarrow$ *to execute/cause-to-run*, *to stop* $\rightarrow$ *to terminate/cause-to-stop*).
3. **Absolute Aspect**: Technical logs require a grammatical aspect indicating complete, binary states (e.g., "online/offline", "connected/disconnected").
4. **Conditional Logic Chains**: Establish sentence patterns that mirror program logic (e.g., "IF input is X, THEN return Y, ELSE return Z").
