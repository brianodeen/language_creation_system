# 17. Space, Flight & Astronomy

## Grammatical Mapping & Analysis
When translating this category into a target language, conlangers and linguists should establish the following grammatical features:
1. **Three-Dimensional Spatial Prepositions**: Standard languages operate in a flat plane. Spaceflight requires prepositions indicating orientation along roll, pitch, and yaw axes (e.g., "dorsal to", "ventral to", "foreward-thrust", "rearward-decay").
2. **Speed & Velocity Derivations**: Formulate suffixes that distinguish speed (scalar: *fast*) from velocity (vector: *speeding-toward-destination*).
3. **Instrumental Passive Cases**: Define grammar for automated tasks carried out by computer systems on behalf of the crew (e.g., "adjusted *by the autopilot*", "scanned *by the array*").
4. **Emergency Suffix System**: Create markers that turn standard pilot commands into absolute high-priority overrides during flight failures.
